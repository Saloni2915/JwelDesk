Column Guide

Header Column Mandatory Validation Rules & Format
item_code Required Unique piece ID / barcode. Cannot repeat in file or stock.
design_code Optional Model / design code. Defaults to item_code if blank.
name Required e.g. "22K Traditional Bridal Choker".
category Required Category name; automatically created if not existing.
metal_type Required Gold, Silver, Diamond or Platinum.
purity Required e.g. 22K (916), 18K (750), 925.
gross_weight Required Gross total weight in grams (e.g. 15.450).
stone_weight Optional Stone / wax weight in grams (defaults to 0.000).
net_weight Optional Net precious metal weight (defaults to Gross - Stone).
selling_price Required Retail price in INR (e.g. 98500.00).
status Optional Available, Sold or Reserved (defaults to Available).

Import Workflow Stages

  1. 1. Upload: Select a valid CSV or Excel file conforming to the column schema.
  2. 2. Validation: Every single row is checked for duplicates, valid karats, non-negative weights, and required fields.
  3. 3. Preview: Review valid vs invalid rows with clear error line highlights.
  4. 4. Atomic Commit: All valid items are saved inside an ACID database transaction.
