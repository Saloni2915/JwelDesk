Expected Columns
Column Required Notes
item_code Yes Unique piece ID / tag / barcode. Cannot repeat inside the file or in the inventory.
design_code No Design / model code, defaults to the piece ID. Several pieces may share one design code.
name Yes Item name, e.g. "22K Gold Solitaire Ring".
category Yes Matched by name; categories that do not exist yet are created automatically.
metal_type Yes Gold, Silver, Diamond or Platinum (case-insensitive).
purity Yes e.g. 22K (916), 18K, 925 Silver.
gross_weight Yes Total weight in grams (up to 3 decimals).
stone_weight No Stone / bead / wax weight in grams, defaults to 0.000. Cannot exceed the gross weight.
net_weight No Precious metal weight in grams. Leave blank to use gross weight minus stone weight.
making_charge No Amount in ₹, defaults to 0.00.
selling_price Yes Amount in ₹, must be greater than 0.
status No Available, Sold or Reserved, defaults to Available.

How the Import Works
  1. Upload a CSV or .xlsx file using the columns listed on the left.
  2. Validate & preview - every row is checked for missing values, wrong metal/status names, weight rules, duplicates and invalid numbers.
  3. Confirm - the valid rows are inserted in a single database transaction. If one row fails, the whole import is rolled back.
  4. Audit - after importing you are returned to the inventory list, which reports how many pieces were added.
